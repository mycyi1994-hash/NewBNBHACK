## 0. 요청 요약 (Claude Design에게)

**데스크톱 웹 서비스** "이자로(Ijaro)"의 화면 디자인 시안을 만들어 줘.
- 기준 폭은 1440px, 콘텐츠 최대 폭은 1200px이다. 모바일 시안은 이번 범위가 아니다. 다만 폭이 줄면 한 열로 접히는 구조로 만든다.
- 산출물 목록은 §9에 있다.
- 시안은 **한국어**로 만든다. 홈과 심사위원 체험 첫 두 화면은 **영어판**도 만든다.
- 실제 서비스는 브라우저 언어를 따른다. 한국어가 아니면 영어가 기본이다. 헤더에서 KO/EN을 바꾼다.

## 1. 제품 한 줄과 대상

**한 줄**: 원금은 USDT 이자 통장(Venus)에 그대로 두고, 이자(또는 정한 적립금)로 미국 주식 조각(bStocks·Ondo)을 **미국 정규장에만** 자동으로 사는 에이전트.

**누가 보나**
| 사용자 | 상황 | 이 화면에서 원하는 것 |
| --- | --- | --- |
| 심사위원 (BNB Chain·Binance Web3 팀, 15분) | 링크를 열고 3분 안에 직접 해 보고 싶다 | 무엇인지 3초 안에 이해, 실제로 돌고 있다는 증거(영수증), 코드로 바로 체험 |
| 저축형 투자자 (30대, 크립토 모름) | 미국 주식을 조금씩 모으고 싶다 | 어려운 말 없이, 숫자가 정직하게, 위험이 숨겨지지 않게 |
| AI 비서 사용자 (Claude Code 등 + Binance Agentic Wallet) | 내 비서에게 맡기고 싶다 | 설치 한 줄, 안전 규칙, 비서와의 대화 예시 |

**심사위원이 보는 순서**(이 순서가 화면 우선순위다): 홈 첫 화면 → 체험(코드 → 종목 → 미리보기 → 영수증) → 기록·데이터(/dx).

## 2. 디자인 원칙 (UX_COPY §1 + 심사 피드백)

1. **크립토 용어를 쓰지 않는다.** UX_COPY §2 치환표를 따른다: 토큰 → "주식 조각/주", 스왑 → "매수", 가스 → "네트워크 수수료", 예치 → "이자 통장에 넣기", tx → "영수증".
2. **지갑 주소(0x…)와 토큰 수량은 첫 화면에 절대 보이지 않는다.** '자세히'를 펼쳤을 때만 보인다. 보유량은 항상 "주"로 표시한다.
3. **한 화면에 결정 하나.** 버튼 이름은 동사로 쓴다("지금 사기", "플랜 멈추기").
4. **숫자는 작아도 그대로 보인다.** 이자 $0.18도 크게, 정직하게. 과장·반올림 부풀리기는 금지다. 금액은 소수 둘째 자리까지, 주 수는 소수 여섯째 자리까지 쓴다.
5. **모든 데이터 블록에 상태 배지를 단다**: 실시간(LIVE) / n분 전(STALE) / 불러올 수 없음(UNAVAILABLE, 이유 포함). 가짜 숫자는 절대 쓰지 않는다. 불러오지 못하면 비워 두고 이유를 보여준다.
6. **기다림과 실패에는 이유와 다음 시각을 함께 적는다**(UX_COPY §4 사유 한 줄).
7. **위험은 숨기지 않되 겁주지 않는다.** 이자 모드를 켤 때 위험 고지 전문을 보여준다. 기본값은 "적립만(안전 모드)"이다.
8. **"곧 출시(coming soon)" 같은 빈 화면이나 버튼은 만들지 않는다.** 없는 기능은 아예 그리지 않는다(분야별 고르기, AI 추천, 웹 지갑 연결은 그리지 않음).

## 3. 비주얼 방향

- **느낌**: 밝고 차분한 금융 앱(토스·로빈후드 웹처럼 단순하고 여백 많게). 크립토 거래소 느낌(네온·다크·차트 과잉)은 피한다.
- **Binance·BNB 로고와 노랑·검정 브랜드 느낌은 쓰지 않는다**(공식 서비스처럼 보이면 안 됨). 푸터에 텍스트로만 "Binance Web3 API · BNB Chain 사용"이라고 표기한다.
- **색**
  - 배경은 흰색과 아주 옅은 회색(#F7F8FA 계열), 글자는 거의 검정(#111), 보조 글자는 회색이다.
  - 브랜드 강조색은 하나만 쓴다. 제안은 깊은 청록(teal)이다. "이자·성장·신뢰" 느낌이고 빨강·초록 시세 색과 겹치지 않는다.
  - 의미 색: 성공(청록), 대기(호박색), 건너뜀(회색), 실패(빨강), 정보(파랑).
  - **가격 오르내림에는 빨강·초록을 쓰지 않는다.** 한국은 빨강이 상승, 미국은 초록이 상승이라 헷갈린다. ▲▼ 화살표와 부호(+/−)를 중립색으로 쓴다.
- **글꼴**: 한국어는 Pretendard, 영어·숫자는 Inter. 금액·주 수는 **고정폭 숫자(tabular numbers)**다. 기본 크기는 16px이다.
- **모양**: 카드 모서리 12–16px, 얕은 그림자나 1px 테두리, 넉넉한 여백(8px 그리드).
- **접근성**: 명도 대비는 WCAG AA 이상이다. 키보드 포커스 표시를 둔다. 색만으로 상태를 구분하지 않는다(아이콘과 글자를 함께 씀).
- **시간 표기**: 사용자 현지 시각으로 쓴다(한국어면 KST). 예: "오늘 22:30 (미국 개장)". 마우스를 올리면 UTC가 보인다.

## 5. 페이지별 명세

### 5.1 홈 (Watch) `/`
목적: 3초 안에 "무엇이고, 진짜 돌고 있고, 어떻게 해 보는지"를 알게 한다.

**① 히어로** (첫 화면, 왼쪽 글·오른쪽 이자 카운터)
- 제목 `home.title`: "이자로 주식을 삽니다"
- 부제 `home.sub`: "원금은 그대로 두고, 이자로만 미국 주식을 조금씩 모아요."
- 버튼 두 개
  - 주 버튼 `home.cta.judge` "심사위원 코드로 체험하기" → /judge
  - 보조 버튼 `home.cta.skill` "내 AI 비서로 시작하기" → /skill
- 오른쪽 **실시간 이자 카운터 카드**(이 서비스의 핵심 장면)
  - 큰 숫자: 지금까지 쌓인 이자. 소수 여섯째 자리까지 초마다 오른다. 블록이 0.45초마다 생기므로 숫자가 계속 움직인다. 예: `$0.184213`
  - 라벨 `home.house.interest` "지금까지 쌓인 이자"
  - 아래 진행 막대: "다음 매수까지 $0.07 남음 · 예상 {날짜}" **[신규 문구]**. 최소 매수액까지의 진행률이다.
  - 작은 글씨: "이자 통장(Venus) 연 3.16% · 보안 점수 93.1" + 상태 배지
  - 이 카드는 '하우스 이자 플랜' 상세로 가는 링크다.

**② 이자로가 직접 돌리는 플랜 (카드 2개)** `home.house.card.title`
- 카드 A — 적립 플랜: "NVIDIA · 매일 $5 · 정규장에만". 항목:
  - `home.house.shares` 모은 주식
  - `home.house.next` 다음 매수
  - 오늘 한도 사용량
- 카드 B — 이자 플랜: "QQQ · 이자로만 · 주 1회". 항목:
  - `home.house.principal` 이자 통장 원금
  - `home.house.interest` 지금까지 쌓인 이자
  - `home.house.shares` 모은 주식
  - `home.house.next` 다음 매수(조건: "이자가 $0.25가 되면")
- 공통
  - 작은 누적 그래프(적립: 모은 주 수, 이자: 쌓인 이자)
  - 상태 배지
  - "기록 보기 →"(플랜 상세)
  - 영수증 개수: "영수증 12개" **[신규 문구]**

**③ 최근 기록 (영수증 피드)**: 이자로가 스스로 남긴 기록, 최신순 10개, "전체 보기"
- 한 줄 구성: 시각 · 플랜 이름 · **결과 배지** · 사유 한 줄 · 금액 · 주 수 · [영수증 보기 ↗](BscScan)
- 결과 배지 4종 **[신규 문구]**: 샀어요(BOUGHT, 청록) · 기다려요(DEFERRED, 호박색) · 건너뛰었어요(SKIPPED, 회색) · 실패(FAILED, 빨강). 아이콘과 글자를 함께 쓴다.
- 사유 한 줄은 UX_COPY §4를 그대로 쓴다. 시안에 아래 다섯 종류를 모두 보여준다.
  - `why.bought.interest` "쌓인 이자 $0.26로 QQQ 0.000351주를 샀어요. 원금은 그대로예요."
  - `why.bought.regular` "정규장에 NVDA 0.022229주($5.00)를 샀어요."
  - `why.deferred.market_closed` "미국 장이 닫혀 있어요. 월요일 22:32에 다시 시도해요."
  - `why.skipped.below_min` "이자가 $0.18 쌓였어요. $0.25이 되면 살게요."
  - `why.skipped.corporate_action.earnings` "TSLA가 실적 발표로 거래가 제한됐어요. 풀리면 다시 시도해요."
- ※ `why.bought.*`의 "기준 주가 대비 {gap}%" 부분은 실제 미국 주가가 있을 때만 붙는다. 없으면 이 부분을 뺀 형태로 그린다.

**④ "왜 정규장에만 사나요?" 인사이트 카드** (토큰화 주식만의 이야기)
- 제목: "장이 닫혀 있을 때 사면 얼마나 비쌀까?" **[신규 문구]**
- 작은 차트: 지난 7일, 같은 종목의 주식 조각 가격과 실제 미국 주가의 차이(%)를 시간 순서로 그린다. 장 마감 시간대는 회색 음영이다.
- 요약 한 줄: "지난 7일, 장 마감 중 가격은 실제 주가보다 평균 +0.4% 비쌌어요 (예시)" **[신규 문구]**
- 출처 표기: "프랑크푸르트 서버에서 10분마다 기록" + 상태 배지 + "기록·데이터에서 자세히 →"

**⑤ 모을 수 있는 주식** (가로 카드 5개)
- 카드 구성
  - 회사 이름(NVIDIA / Tesla / Microsoft / Nasdaq-100 ETF / Apple), 티커
  - 1주 가격
  - 장 상태
  - 살 수 있는 곳: 발행사 배지(bStocks / Ondo)
  - 최소 주문(Ondo는 $5.01)
- **Apple 카드**: "Ondo에서만 살 수 있어요 · 최소 주문 $5.01" **[신규 문구]**
- 설명 한 줄: "주식 조각 1개는 실제 주식 약 1.0008주예요(배당이 반영돼 조금씩 바뀌어요)" **[신규 문구]**
- 배수가 바뀔 예정인 종목에는 "10월 1일부터 주식 수 표시가 바뀌어요" 배지를 단다. **[신규 문구]**, 예시 1개만.

**⑥ 믿을 수 있는 이유** (아이콘 3~4개 가로 띠)
- "모든 매수는 먼저 블록체인에서 미리 돌려봐요"
- "한도: 1회 $25 · 하루 $50"(캡은 화면에 표시한다는 원칙)
- "지킴이: 이상 없음 · 마지막 점검 {time}"(`plan.guardian.ok`)
- "서버는 여러분의 지갑 열쇠를 보관하지 않아요"
- ※ 모두 **[신규 문구]**다. 단 `plan.guardian.ok`는 기존 문구다.

**홈 변형 시안(1개 더)**: **주말 버전.**
- 헤더 배지는 "미국 장 마감 · 다음 개장 월 22:30"이다.
- 적립 플랜 카드의 다음 매수는 "월요일 22:32"다.
- 피드 맨 위에는 DEFERRED 기록이 있다.
- 이자 카운터는 주말에도 계속 오른다. 이게 포인트다.

### 5.2 체험하기 (Judge Mode) `/judge`
목적: 심사위원이 코드 하나로 3분 안에 실제 매수 영수증까지 간다.

**레이아웃**
- 상단에 6단계 진행 표시: ① 코드 ② 종목 ③ 방식·금액 ④ 미리보기 ⑤ 실행 ⑥ 영수증
- 왼쪽 넓은 칸은 현재 단계 내용이다.
- 오른쪽 좁은 칸(스크롤해도 고정)은 **요약 패널**이다: 종목 · 방식 · 금액 · 사는 시간 · 한도(`judge.code.hint`의 ${cap}) · 장 상태

**① 코드**
- `judge.code.title` "심사위원 코드를 입력해 주세요"
- 입력칸 1개 + [확인]
- 도움말 `judge.code.hint` "코드 하나로 최대 $5까지 체험할 수 있어요. 돈은 이자로의 지갑에서 나가요."
- 오류 상태 **[신규 문구]**: "코드가 맞지 않아요" / "이 코드는 한도를 다 썼어요"

**② 종목 고르기**
- `judge.pick.title` "어떤 주식을 모을까요?"
- 종목 카드 5개(홈 ⑤와 같은 카드를 선택형으로). 선택 시 테두리는 강조색이다.
- 카드 아래 `judge.pick.issuer.auto` "발행사는 자동으로 골라요 (bStocks)"
- **Apple 카드는 비활성**: "Ondo에서만 살 수 있고 최소 주문이 $5.01이라, 체험 한도($5)로는 살 수 없어요" **[신규 문구]**
- 분야별 고르기(`judge.pick.sector`)는 **그리지 않는다**(이번 범위 아님).

**③ 방식·금액·시간**
- 방식 카드 2개
  - `judge.mode.safe` "적립만 (기본)" + `judge.mode.safe.desc`: 선택된 상태가 기본이다.
  - `judge.mode.yield` "이자로 사기" + `judge.mode.yield.desc`: 선택하면 **위험 고지 모달**이 뜬다(§5.5 전문, 체크박스 "이해했어요" + [동의하고 켜기]).
- 금액 `judge.amount.label` "이번에 살 금액": 버튼형 선택 $2.50 / $5.00(최대 = 체험 한도)과 직접 입력.
- 사는 시간
  - `judge.window.regular` "미국 정규장에만 사기 (권장)"
  - `judge.window.anytime` "장 마감 중에도 사기 (가격이 기준과 다를 수 있어요)"
  - 지금 장이 닫혀 있으면 두 선택지 아래에 각각 설명을 붙인다.
    - 정규장: "다음 개장 오늘 22:30에 자동으로 사요" **[신규 문구]**
    - 장 마감 중: "지금 바로 사요 · 한도 절반($2.50) · 최근 7일 장외 가격은 평균 +0.4% 비쌌어요" **[신규 문구]**
- 이자 모드를 고르면 금액 대신 "넣을 원금"과 예상 이자를 **정직하게** 보여준다. 작은 숫자도 그대로 쓴다. 예: "$5를 넣으면 1주일 이자 약 $0.003 · 이자 매수는 이자로가 직접 돌리는 플랜에서 볼 수 있어요" **[신규 문구]**

**④ 미리보기**
- `judge.preview.title` "이렇게 진행돼요"
- 문장형 요약 `judge.preview.line`: "5달러로 NVDA 약 0.0222주를 받아요. 네트워크 수수료 약 $0.02."
  - 실제 미국 주가가 있으면 "기준 주가 대비 +0.3%."를 붙인다.
- 결과 배지
  - 성공 `judge.preview.simulated` "블록체인에서 미리 돌려봤어요 · 성공"(청록 체크)
  - 실패 변형 시안 `judge.preview.failed` "미리 돌려봤더니 실패했어요: {reason}. 돈은 나가지 않았어요."
- **견적 유효시간 표시**: "이 가격은 25초 동안 유효해요" + 줄어드는 원형 타이머. 끝나면 자동으로 새 가격을 받는다. **[신규 문구]**
- '자세히' 접기 영역: 경로(거래소 이름), 가격영향 %, 받을 주식 조각 수(토큰 수), 발행사, 컨트랙트 주소(여기서만 0x…).
- 주 버튼 `judge.run.cta` "지금 사기", 보조 버튼 "뒤로".

**⑤ 실행 중**
- 3단계 진행 표시 `judge.run.progress.{approve|swap|confirm}`: "사용 허용 중… → 매수 중… → 기록 확인 중…"
- 각 단계가 끝나면 체크 표시와 소요 시간이 붙는다.

**⑥ 영수증**
- `judge.done.title` "샀어요" + 큰 체크
- `judge.done.line` "NVDA 0.022229주 ($5.00) · 영수증 보기"(BscScan 새 창)
- 사유 한 줄(`why.bought.regular`)
- 안내: "이 플랜은 7일 동안 자동으로 돌아요. 나중에 다시 와서 기록을 보세요." **[신규 문구]**
- 버튼
  - `judge.stop.cta` "플랜 멈추기"(보조, 확인 대화상자 있음)
  - "플랜 기록 보기 →"(플랜 상세)
- 이자 모드였다면 멈추기 옆에 `judge.stop.yield.note` "이자 통장에 있던 원금을 전부 꺼내요. 주식은 그대로 남아요."를 붙인다.

- (c) **한도 도달**: `why.skipped.daily_cap` "오늘 한도($50)를 다 썼어요. 내일 다시요."
- (d) **위험 고지 모달**: §5.5 참고.
